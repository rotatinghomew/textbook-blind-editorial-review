# 教材分段盲审与签发效力

本项目资料用于跨单位交接演练。记录和名称均为合成，时间、角色与对象编号在同一份资料内保持原始对应。

## 资料格式

`data/` 按来源分存 UTF-8 JSON 对象数组，`data/format.json` 描述各来源字段、引用和单号作用域。对象中的空值表示材料未提供相应事实，具体含义见后文。

sections 的 slot 跨稿次稳定。正文、共享材料和作者表来自编辑，材料对象号指向不可变内容。obligations 描述每节学科专家与教学专家的独立最低要求，同一人即使具有两类资质，在同一节只可占一个角色。relations 的 since 是关系开始时间，reported 是办事方可见时间，关系从 since 起涉及该两人。已有意见能否沿用需要核对节段内容、支撑资料、适用范围和按实际历史核验的合格性。作者表调整本身要重验回避，有效内容和证据都保持时仍合格的意见可以继续计入。

## 本地使用

使用 Python 3.11.2 标准库。检查样例数据及随附的本地接口契约时，在本项目根目录运行：

```bash
python3 -m unittest discover -s tests -v
```
